# Fork features

This fork extends [sauravhathi/atsresume](https://github.com/sauravhathi/atsresume) with the features below. Each file describes one feature: what it does, the data it adds to the resume JSON, and how it should behave. They were written while rebuilding the fork on top of the restructured upstream (Next.js 15, App Router, `src/` layout), and serve as the spec for each port.

| # | Feature | Spec |
|---|---------|------|
| 0 | Baseline fixes to upstream | [00-baseline-fixes.md](00-baseline-fixes.md) |
| 1 | Work experience details: work type, location, technologies | [01-work-experience-details.md](01-work-experience-details.md) |
| 2 | Grouped skills | [02-grouped-skills.md](02-grouped-skills.md) |
| 3 | Load, save and refresh resume files | [03-load-save-refresh.md](03-load-save-refresh.md) |
| 4 | One-column ATS layout | [04-one-column-layout.md](04-one-column-layout.md) |
| 5 | Resume language (English / French) | [05-resume-language.md](05-resume-language.md) |
| 6 | Small changes | [06-small-changes.md](06-small-changes.md) |
| 7 | Editor panel redesign | [07-editor-panel.md](07-editor-panel.md) |
